🪪 هویت پروژه

این مخزن، نسخهٔ نخست و کلاسیک پروژهٔ سوپال (Sopal) است — پیش از بازنویسی ماژولار با Livewire 3 + Flux UI (که در ~/projects/Sopal مستقل نگه داشته شده). هدف محصول ثابت است: پلتفرم چندمستاجری برای رستوران/فست‌فود و دفتر حقوقی.

  • کاملاً فارسی و RTL با فونت Vazirmatn و هویت رنگی سوپال (فیروزه‌ای/سبز دریایی)
  • دارای لندینگ با موتیف «کشند/موج»، صفحات درباره/تماس/قیمت‌گذاری
  • فرم‌های تماس، خبرنامه و پیش‌سفارش (ذخیره در SQLite)
  • احراز هویت جلسه‌ای + داشبورد کاربر + پنل ادمین کامل

🔐 سیستم احراز هویت (Controller-based)

ورود (Login)

  • فقط ایمیل + رمز عبور (نه یوزرنیم)
  • نرمال‌سازی ایمیل به lowercase در LoginRequest::prepareForValidation() (مستقل از حروف بزرگ/کوچک) — سپس جستجوی سادهٔ برابری
  • Throttle: حداکثر ۵ تلاش در دقیقه (throttle:5,1)
  • بررسی is_active؛ کاربر غیرفعال خطا می‌گیرد
  • پس از ورود: session()->regenerate() و هدایت به داشبورد
// LoginRequest::prepareForValidation() — ایمیل به lowercase نرمال می‌شود
$this->merge(['email' => strtolower(trim((string) $this->input('email')))]);

// AuthController@login — جستجوی سادهٔ برابری روی مقدار نرمال‌شده
$credentials = $request->validated();
$user = User::where('email', $credentials['email'])->first();
if (! $user || ! Hash::check($credentials['password'], $user->password)) {
    return back()->withErrors(['email' => 'ایمیل یا رمز عبور اشتباه است.']);
}
if (! $user->is_active) { /* خطای غیرفعال */ }
Auth::login($user, $credentials['remember'] ?? false);
$request->session()->regenerate();
return redirect()->intended(route('dashboard'));

ثبت‌نام (Register)

  • تحت گیت Setting::get('registration_enabled') === '1' — در غیر این صورت 404
  • اعتبارسنجی: name، ایمیل (یونیک بدون حساسیت حروف)، رمز min:6 + تکرار
  • نقش پیش‌فرض user و is_active = true
  • هدایت به صفحهٔ ورود با پیام موفقیت

تغییر رمز عبور (ویژگی جدید — uncommitted)

  • مسیرهای GET/PATCH /password با نام‌های password.edit / password.update
  • اعتبارسنجی current_password (قانون Laravel) + min:6 + confirmed
  • کست hashed روی مدل — ذخیرهٔ امن خودکار

جریان کلی

🛣️ مسیرها (routes/web.php)

# Public
GET  /                  → home (LandingController@index)
GET  /pricing           → pricing
GET  /demo              → ریدایرکت به demo.sopal.ir
GET  /about             → about
GET  /contact           → contact
POST /contact           → contact.store   (RateLimit 3/ساعت)
POST /subscribe         → newsletter.store
POST /preorder          → preorder.store
GET  /api/stats         → api.stats (JSON)

# Guest
GET  /login             → login      (throttle:5,1)
POST /login             → login
GET  /register          → register   (throttle:5,1)
POST /register          → register   (404 اگر غیرفعال)

# Auth (auth + active)
POST /logout            → logout
GET  /dashboard         → dashboard
GET  /password          → password.edit    (جدید)
PATCH /password         → password.update  (جدید)

# Admin (auth + active + admin)
GET    /admin                    → admin.dashboard
PATCH  /admin/users/{u}/toggle-active  → admin.users.toggle-active
PATCH  /admin/users/{u}/update-role    → admin.users.update-role
DELETE /admin/users/{u}                → admin.users.destroy
PATCH  /admin/settings/registration    → admin.settings.registration
